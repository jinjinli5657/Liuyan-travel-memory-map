使用说明

这是一个你的私人旅行地图，所有数据都保存在本机的 data.js 里。地图完全离线，不需要联网。

📍 添加城市

打开 data.js，在 myCities 数组里加一条：

{
  name: "巴黎",
  country_code: "FRA",   // 必须对应 myCountries 里的 code
  lat: 48.8566,
  lng: 2.3522,
  visitDate: "2024-03",
  photos: ["photos/paris1.jpg"],
  story: "塞纳河畔的午后……"
}

保存后浏览器刷新即可看到效果。

📷 添加照片

把 jpg/png 放进 photos/ 文件夹，在 city 记录的 photos 数组里引用文件名即可。

✏️ 在应用里写简介、贴照片（推荐）

点开任意国家或城市的弹窗，点里面的 ✏️ 编辑简介/照片：

  • 文字框直接写故事 / 感受 / 攻略；
  • 点虚线框或把照片拖进去，即可嵌入照片（自动压缩，存在本浏览器）；
  • 点「保存」后，下次再点这个地点就会浮现这段文字和照片。

想永久备份或换电脑：点右下角 💾 备份数据 下载一个 JSON（含城市、简介、照片），在别处用 📂 恢复数据 导入即可。

🌍 标记去过的国家

直接在地图上点任意国家（不需要改任何文件），弹窗里点 ＋ 标记我来过 即可——该国立刻上色、出现在统计里；再点一次可取消。城市清单从内置主数据自动带出，没有的城市也能手动添加。

⚙️ 完全离线

所有地图数据、世界地图 SVG、D3.js 都已下载到本地 assets/ 文件夹，无需任何网络。

🔍 缩放与平移

滚轮可放大/缩小，按住鼠标拖拽可平移地图，左下角的 + / − / ⤾ 按钮也能放大、缩小和一键重置视图。

✅ 勾选去过的城市

点开任意国家的国旗，会下拉出该国的城市清单，把去过的城市勾上即可，地图上立刻出现城市点，右上角"个城市"计数实时更新。勾选状态自动存在本浏览器里，刷新不丢。

选完后数据已自动存在本浏览器；想长期保留或换设备，用右下角 💾 备份数据 导出 JSON 即可。

💾 数据备份 / 恢复（防丢失）

勾选的城市、写的简介和照片都只存在本浏览器里。如果换电脑、清了浏览器缓存、或用不同方式打开本文件（比如从 file:// 改成 localhost，或反过来），这些数据可能"看不见"。

建议定期点 💾 备份 下载一个 travel-backup.json；在别处/别的电脑用 📂 恢复 导入，城市立刻回来。这比依赖浏览器存储可靠得多。

✅ 只要你勾城市 / 保存简介 / 标记国家，页面会自动存进你自己的浏览器。别人用同一份工具、各自浏览器互不可见；用「💾 备份数据」才能把数据带走或换电脑。
